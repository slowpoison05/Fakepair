# FakePair

Frontend MVP for **FakePair — Fake Girlfriend & Fake Boyfriend**.

## Included
- Responsive landing page
- Girlfriend / boyfriend creation flow
- Name and vibe selection
- Chat-style product preview
- Mystery Mode explainer
- Transparent AI / human-participant disclosure
- Privacy and safety positioning
- No backend or API keys required

## Run
Open `index.html` or deploy the repository on any static web host.
